# Arquitectura de datos e IA

Guías de estudio y recursos para avanzar hacia la arquitectura de datos, la arquitectura de IA y la automatización responsable de procesos de gobierno de datos.

## Guías

- [Roadmap: Arquitectura de Datos e IA](./Data-Architect-Roadmap.md) — plan de cuatro semanas, ruta de certificaciones AWS y GitHub, uso de Udemy Enterprise, Percipio y Pluralsight, y proyecto de gobierno asistido por agentes.
- [Big Data Foundations: The Modern Data Ecosystem](./BigDataFoundations-Course-Summary.md) — resumen en español sobre plataformas de datos modernas, pipelines, lakehouse, gobierno y tendencias de IA.

## Enfoque

La ruta combina fundamentos transferibles de arquitectura con AWS para datos e IA y GitHub para desarrollo agentic. Los agentes se plantean como asistentes con permisos mínimos, validaciones, trazabilidad y aprobación humana para cambios sensibles.

> Los documentos son material educativo. Verifica las guías y la disponibilidad actuales de los exámenes directamente con sus proveedores. La transcripción original del curso no está incluida en este repositorio.
